# PC-TEAM1
Pre-Capstone Team 1

I worked on this project as part of my TLG software development internship. My collaborators were Titus Kovalik (github.com/GreenSpaceman22) and Tyler Poepping (github.com/SSPENELOPE).

This was the first part of our capstone project. We utilized 2 x 3-day sprints to work on our backlog, taking the user stories and turning them into functional code.

I worked mainly on the mapping for this one. I had a major realization toward the end of the second sprint where I finally realized that Titus and Tyler were reading/writing to/from JSON files to populate Java objects - this was a pretty big turning point in my conceptual understanding of OOP.

The end result of the user stories we followed was a game featuring text-based input and ASCII graphical output. I had a lot of fun with this one, and Titus and Tyler were awesome to work with.
